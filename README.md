# 知己 · 函数课堂

让学生当老师，向“小知同学”讲解函数知识，再判断并纠正小知的例题解答。依据[已确认方案](./函数章节以教促学系统-确认方案.md)实现，部署目标为阿里云。

## 已实现

- 独立师生登录、班级管理、CSV / TSV 名册导入；学号作为账号，默认密码为学号后四位，保留前导零，不强制改密。教师可重置密码并使旧登录失效。
- 13 个可编辑草稿课时、26 道正误例题与逐项评价标准；教师审核后发布，课堂保留任务快照。[内容说明](./docs/curriculum.md)。
- 教师控制自主阅读、学生讲解、小知试做、判断纠错及结束阶段；待补保留、补做关联原课堂并单独记录。
- 平板适配的浅色界面；文字、上下标与数学符号、手写图片；关闭时段后只读回顾。
- 服务端调用 DeepSeek，对话与图像上下文、逐项证据评价、同一问题两轮追问后明确纠错。例题展示使用审核后的解答版本，保留预设数学内容。
- 原始消息先入库，随后异步生成反馈；失败保留原文并可重试；幂等提交；迟到的模型反馈不能覆盖已经切换的课堂阶段。
- 教师查看全班进度、学生对话、图片与模型评价依据；导出 ZIP，包含 Excel 和图片附件。

前后测在线下进行，成绩在系统外管理。模型过程评价不能作为独立测验成绩。

## 本地运行

需要 Node.js 22.13 或更高版本（本项目使用 Node 内置 SQLite），建议使用 Node.js 22 的最新补丁版本。

```bash
npm ci
cp .env.example .env
npm run setup
npm run dev
```

`setup` 交互创建教师账号，教师密码至少12位，终端输入隐藏。浏览器访问开发服务打印的地址，通常为 `http://127.0.0.1:5173`。

在 `.env` 中填写 `DEEPSEEK_API_KEY`，重启服务后生效。默认接口地址为 `https://api.deepseek.com`，模型调用名为 `deepseek-flash`。模型名称与图片、JSON 请求格式依据 [DeepSeek 模型文档](https://api-docs.deepseek.com/quick_start/pricing/)、[视觉文档](https://api-docs.deepseek.com/guides/vision/)、[JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)配置。密钥只保存在服务端，不进入浏览器构建产物。

未配置密钥时，教师仍可准备名册和课程；界面明确显示模型尚未连接，不生成冒充真实模型的反馈。

首次进入后：创建班级 → 导入学生 → 备课审核并发布 → 选择课时开启课堂 → 按阶段推进。

名册示例：

```csv
学号,姓名
20260101,林予安
20260102,陈知夏
```

如果已经使用表格软件编辑名册，请将学号列设为文本后保存 CSV / TSV，避免前导零在导出前被丢弃。

## 本机演示

演示数据与正式本地数据使用不同目录。演示模式只允许绑定本机地址，生产环境拒绝开启。

```bash
DEMO_MODE=true DATA_DIR=./data/demo npm run dev
```

| 身份 | 账号 | 密码 |
| --- | --- | --- |
| 教师 | teacher | demo-teacher-2026 |
| 学生 | 20260101 | 0101 |

演示环境使用明确标注的固定反馈，不进行真实理解评价。演示课时仍需要教师审核发布。上述账号只在显式演示模式、空的演示数据库中创建。

## 检查与构建

```bash
npm run typecheck
npm test
npm run test:load
npm run build
npm start
```

`test:load` 会在临时数据库中创建50名学生，模拟同时提交、保存、反馈和全班切换阶段，输出 `artifacts/load-test.json`。它使用带延迟的模拟评价器，不消耗真实模型额度，也不代表阿里云或 DeepSeek 的实际延迟与吞吐。

自动测试覆盖访问权限、答案字段隔离、名册唯一性、幂等提交、图片访问与导出、晚到反馈、待补与补做、首次判断、两轮追问、失败重试、密码重置、图像请求格式和历史证据保留。

## 阿里云部署

已提供 Dockerfile、Compose、Caddy HTTPS 配置和数据库备份脚本。按[阿里云部署说明](./docs/deployment-aliyun.md)配置服务器、域名及服务端密钥。当前没有使用任何云端凭据，也没有实际部署到阿里云。

## 目录与数据

| 路径 | 内容 |
| --- | --- |
| `src/` | React 师生界面、数学渲染与触控交互。 |
| `server/` | 认证、课堂状态、模型调用、图片和研究数据导出。 |
| `server/content/lessons.json` | 依据导学案整理的初始课时草稿。 |
| `shared/` | 师生端与服务端共享的类型及阶段定义。 |
| `tests/` | 通过公开 HTTP 接口验证课堂行为的集成测试，以及模型接口契约测试。 |
| `data/` | 本地 SQLite、手写图片及备份；已加入 Git 忽略。 |
| `docs/` | 课程来源、部署和验证记录。 |

当前采用单实例 Node.js 服务和 SQLite WAL，数据库与图片同置持久化数据卷。此版本不应通过复制容器数量直接水平扩容；扩容时应先调整共享存储、数据库及后台任务协调。

修改任务库的初始 JSON 不会覆盖已入库的教师内容，已有课时需从备课界面编辑、重新审核发布。历史课堂始终使用原快照。

## 交付前后的验证边界

自动测试和生产构建的实际结果记录在 [验证说明](./docs/verification.md)。正式使用前还需在目标阿里云环境配置真实模型、由教师审核课时，并用实际平板验证长公式、手写图片、课堂并发和反馈质量。
