# 50人真实 AI 并发测试

## 结论

本次测试通过。50名虚拟学生连续进行两轮同时提交，共100条作答，全部保存并生成可读取的真实 AI 反馈，没有请求失败、超时、429限流、重复学生消息或最终待复核。教师与学生的课堂阶段同步正常。

当前配置最多同时处理12个模型请求，其余排队，因此“50人同时使用”不是向模型服务同时发出50个请求。讲解轮全部反馈约12秒完成，判断纠错轮约13.2秒完成；本次测量支持保留当前 `AI_CONCURRENCY=12` 配置。

这是一次本机应用到真实 DeepSeek 的文本负载测试，不是阿里云生产环境、50台真实设备或整个课时的持续负载验收。

## 环境与方法

- 时间：2026-11-17 05:34:03 至 05:34:34 UTC。
- 本机 macOS，Node.js v22.22.3，真实应用 HTTP 接口和临时 SQLite 数据库。
- 模型调用名及接口返回模型名：`deepseek-flash`；接口主机 `api.deepseek.com`；提示词 `teaching-v2.1`。
- `AI_CONCURRENCY=12`，`AI_TIMEOUT_MS=60000`，关闭演示模式。
- 创建50个独立测试账号，通过登录、名册导入、课时发布、教师阶段控制及学生提交接口运行。
- 课时为“函数的概念”。讲解轮包含完整解释、部分解释、明确数学错误等5种文本；判断轮包含充分理由、反例、不充分理由及错误判断等5种文本，每种10人。
- 每2.5秒并发读取50名学生的课堂状态及1份教师总览，同时观察消息落库、反馈、模型请求时延和队列等待。
- 在讲解完成后切到查看例题，确认50名学生都读到新阶段，再进入判断纠错进行第二轮提交。
- 使用虚拟内容，未读取或修改正式课堂数据库；结束后关闭测试服务并删除临时数据库。

## 实测指标

| 指标                  | 讲解轮        | 判断纠错轮    |
| --------------------- | ------------- | ------------- |
| 同时提交人数          | 50            | 50            |
| 接收／保存／获得反馈  | 50／50／50    | 50／50／50    |
| 失败／最终待复核      | 0／0          | 0／0          |
| 提交确认 P50／P95     | 256／270毫秒  | 211／232毫秒  |
| 反馈完成 P50／P95     | 6.92／11.46秒 | 8.10／13.21秒 |
| 全部反馈完成          | 11.97秒       | 13.21秒       |
| 排队等待 P50／P95     | 4.35／9.01秒  | 4.19／10.35秒 |
| 课堂状态读取次数      | 255           | 306           |
| 课堂状态读取 P50／P95 | 306／350毫秒  | 521／619毫秒  |
| 状态读取失败          | 0             | 0             |

反馈完成从本轮50人批量提交开始计时，以测试程序观察到消息完成并落库为准，检查间隔约100毫秒；不包含浏览器绘制和真实设备网络耗时。学生界面仍按自身轮询周期获取最新反馈。

模型服务共收到101次请求，峰值同时请求数12；单次请求 P50 为2.59秒、P95 为3.45秒、最大3.83秒。没有非200响应、超时或限流。判断轮1条作答触发评价器内部重试，第2次成功，最终正常呈现。

教师切换阶段并让50名学生读取新阶段共469毫秒。两轮结束后，教师总览均显示50名参与者，等待反馈人数归零；学生均能读取自己的作答和相应反馈，未产生重复作答。

判断轮50个预设结果均符合预期：30份充分理由及修正通过，10份只有判断、缺少理由的回答未通过，10份错误判断未通过。这验证的是本次5类样例，不代表模型对所有数学内容均能正确评价。

接口返回用量合计：输入272,992 tokens（其中缓存命中203,776），输出59,226 tokens。实际费用以服务商账单为准。

## 重复运行

本机 `.env` 中配置真实服务密钥后执行；此命令会产生模型调用费用：

```bash
npm run test:load:ai
```

脚本为 [`scripts/load-test-ai.ts`](../scripts/load-test-ai.ts)。运行时使用正式评价器、并发队列、证据校验和重试逻辑，不修改模型请求参数。

完整结果写入 `artifacts/ai-load-test.json` 和带时间戳的同名文件，包含分轮指标、每条虚拟作答的反馈／评价及脱敏模型请求指标。产物目录被 Git 忽略，不包含密钥。脚本经过独立 TypeScript 类型检查和格式检查。

同日另运行了原有模拟负载基线：50条消息全部接收并获得模拟反馈，提交确认 P95 为205毫秒，全部模拟反馈454毫秒完成。该基线仅用于区分应用开销与真实模型等待时间。

## 部署后仍需验证

阿里云上的 CPU、内存、出口网络、Nginx 和校园平板网络尚未纳入本次测试。部署后应在目标服务器重复本测试，并用实际学生终端验证访问和轮询；手写图片、长对话、多班同时使用及持续整节课负载仍需单独检查。
