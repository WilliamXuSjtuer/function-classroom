# 教师全班进度总览

## 已确认的范围

- 默认呈现当前阶段的全班总览；讲解和当前例题分别统计已完成、进行中、未提交、需要帮助人数。
- 紧凑学生卡片墙显示姓名、学号、状态及简短进度。讲解显示已完成检查项数，判断阶段显示当前例题状态。
- 按学号固定排序，点击顶部人数筛选；状态变化不自动改变学生顺序。
- 点击学生，在右侧详情栏查看当前进度、待补知识点、最近一轮问答，可展开完整对话。保留全班视图。
- 当前阶段及教师切换按钮醒目可见。教师自主决定节奏，不设置完成比例阈值、推进提醒或自动切换。
- 学生端不增加阅读确认按钮。自主阅读和查看解答阶段不推算阅读完成率，由教师把握时间。

## 统计与交互口径

- 人数分母使用当前课堂参与名单，包含未提交的学生；补做课堂只统计实际参与补做的学生。
- 已完成、进行中、未提交、需要帮助为互斥学习状态。等待反馈、评价失败、待复核另行标记，并可单独筛选，不与学习状态混为一类。
- 先前已经核验的完成状态，在新提交等待反馈、系统失败或待复核时仍保留，同时展示对应处理状态。
- 讲解只统计本课检查项；判断只统计当前例题，旧题或旧阶段的问题不计入当前阶段异常人数。
- 阅读、查看解答和结束阶段只标明阶段，不生成虚假的完成比例。
- 每3秒刷新。筛选在切换阶段或例题后重置为全部，学生排列保持稳定。刷新失败明确提示数据尚未更新。
- 详情栏在切换学生时不展示上一位学生的内容；切换课堂清除选中学生。过时响应不能覆盖较新的课堂阶段。
- 保持现有教师权限、手动阶段控制、模型评价及导出统计含义。

## 验收

- 覆盖未提交、处理中、部分完成、需要帮助、已完成后评价失败/待复核等状态。
- 验证阶段/题目切换、仅补做参与者计数、固定学号排序和状态筛选。
- 检查右侧详情、最近问答与完整对话展开、键盘关闭和小屏布局。
- 用约50名模拟学生检查卡片密度；不修改正式课堂数据或调用真实模型。
