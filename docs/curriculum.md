# 函数章节课时任务库

本文件说明 `server/content/lessons.json` 的内容来源、课时映射与审核事项。初始任务共 13 课时、26 道例题，全部为 `draft`。教师应在教师端核对和修改后发布，文件中的数学整理不代表已经完成教师审核。

## 来源与课时对应

材料来自项目中的 [导学案](../导学案.pdf) 和 [课时安排](../课时安排.jpg)。页码均指 PDF 页序，从 1 开始；已检查的页面其纸面页码与 PDF 页序一致。

例题使用原题的核心关系或明确标注的改编形式，智能体的正误解题过程为本任务库重新编写。`source` 字段给出每题依据，避免把新写的错解当作原文答案。

反函数内容确实存在于导学案第 82–90 页，因此两节选学课使用这些页面作为依据，不需要虚构来源或自动补充未提供的教材章节。

## 数据结构与使用

根结构为课时数组。每课包含 `id`、`order`、`title`、`subtitle`、`chapter`、`duration`、`sourcePages`、`material`、`objectives`、`checklist`、`exercises`、`status`。

- `material` 为学生自主阅读材料，采用 Markdown 与 `$...$` 数学表达；不包含该课例题的专门答案列表。
- `objectives` 记录本课的学习目标。
- `checklist` 中每项包含稳定 ID、学生可理解的标签和教师／模型使用的评价标准。
- `exercises` 中每题保存题干、智能体尝试、真实对错、正确解答、错误解释、提示及来源。
- 「函数的单调性（一）」第二题采用教师提供的教材例 9。本课两题均展示错解。其余课时初始各有一道正确解答和一道典型错解，教师可在备课时调整。
- `attempt` 表示智能体实际展示的解题过程，不能用错误标签或正确答案替换它。
- `isCorrect`、`correctAnswer`、`errorExplanation` 和 `hint` 属于教师／服务端判定信息，首次作答前不得透出到学生 API 或页面中。
- 评价依据需要关联实际学生消息；这份文件只定义标准，不能提前生成学生达标结果。

选择的例题均可由文本与数学表达完整描述。涉及图像的材料安排学生用函数关系、坐标交换或草图作解释；没有把 PDF 中无法可靠读取的图形擅自转成题目。学生仍可上传自己的函数草图进行讲解。

## 数学与来源核对说明

已使用 PDF 页面渲染检查函数概念、分段函数、奇偶性、单调性、最值、建模、零点、二分法、反函数和复习中的关键页面。文本提取中有字体乱码、上下标位置丢失等情况，因此任务中的公式重新排写，未直接使用乱码提取结果。

需要保留的数学细节：

1. **相同函数。** 以定义域相同、对应规则相同判断；解析式写法不同也可能表示同一规则。材料原填空附近的“定义域、值域、解析式相同”不宜直接作为机械字符串判定标准。
2. **奇偶性。** 定义域必须关于原点对称。奇函数在 0 处有定义时，才可使用 `f(0)=0`。非对称区间上的偶次多项式不能仅凭表达式判为偶函数。
3. **单调性。** 导学案明确区分“增／减”与“严格增／严格减”。本任务库的证明例题使用严格不等号，并在题目与解析中明确用“严格递增／严格递减”。教师修改时应保持术语与不等号一致。
4. **最值。** 候选界限需要能够在定义域内取到。开区间上的端点值只可作为边界，不能直接记为最值。
5. **现实定义域。** 盒子的各边要为正；等腰三角形不仅要求边长为正，还要满足三角形不等式。
6. **零点。** 零点是自变量的数值，图像交点才是坐标点。正负不等式的解集需要判断各段函数值符号。
7. **二分法。** 零点存在定理同时要求闭区间连续与端点异号，只保证至少一个零点。第一次二分的示例采用 `x³+3x−1`，中点 `0.5` 的函数值为 `0.625`。原导学案部分精度表格信息较密，任务没有把未逐项核对的四舍五入停止次数当作答案。
8. **反函数。** 正确交换定义域和值域，并按原定义域选择根式分支。严格单调是可逆的充分条件，不能无条件说成必要条件。反函数图像关于 `y=x` 对称，坐标交换不附带变号。
9. **综合性质。** 一项递增、另一项递减不能直接推出和函数的单调性。复习题通过任意两点作差给出结论。

教师发布前应最终确认本班的教学进度、例题难度、正误配置、评价术语以及每项追问与纠错的依据。所有课时初始为草稿，方便完成这一检查后再进入课堂。
