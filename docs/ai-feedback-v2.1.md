# 课堂反馈修复：teaching-v2.1

依据第二次课堂导出中“函数的表示方法”的记录修复。原始问题是：学生只说“你做的对”被判理由充分；第二题通过后仍被追问；“什么分段函数”消耗选段追问次数，端点还没问就给了答案；小知将学生的讲解说成“我都讲清楚了”。

## 判定与反馈

- 核对原话来源之后，再排除明确的纯表态、收尾和无上下文的“满足”等确认语，不能单独用作判断理由或纠正证据。已在本题给过的有效理由仍可跨轮使用，不按回答字数判定。
- 这是针对已识别表达的保守校验，不是数学语义证明器。未知说法、真实理由是否数学充分仍需模型评价与教师复核，不能宣称消除所有误判。
- 正确题仍需要解释依据；错误题可跨轮合并错误原因和修正答案。整课检查项未全部完成不阻止当前例题通过。
- 例题通过后由服务端生成学生口吻的明确收尾，等待教师切换任务。讲解全部达标也使用“你教给我了，我明白了”，避免角色归属说反。其他生成反馈在提示词中约束同一角色。
- 达标后的已识别收尾消息不再请求模型、不再产生学习评价，不增加提示次数。原话和回复完整保存。提出反对意见、改变判断或补充数学内容仍进入评价；新评价失败或待复核不撤销此前有效状态。
- 学生端完成后允许不重选判断直接收尾，也可继续补充或修正。教师保留阶段切换权。

## 细项与澄清

- 13课时的52项默认审核标准细分为100个要点，均给出稳定子项编号。包括选段/端点、三种表示法各自的用途/限制、图像点集/唯一性，以及二分法连续性/端点异号等。
- 只有原标准文本完全匹配时才应用细分。教师自定义的标准仍以其文本为准，每行一个要点；不改已发布课时或课堂快照。
- 各细项分别累计证据、分别计追问次数。已解决细项不继承到新问题；同一未解决细项仍最多两次追问，然后明确补充或纠错。
- 已识别的“什么分段函数”“能解释一下吗”等澄清请求先补足问题信息，不消耗追问次数，不提前给出另一知识点的答案。识别规则保守，未识别表达仍交给模型，研究时需回看原话。
- 旧的粗粒度证据不自动扩展成多个已达标细项。后续正常评价可根据保留的学生原话重新核对；历史消息和旧评价保持原样。

## 例题数据与统计口径

SQLite增加一个可空的`messages.submission`元数据列，启动时自动迁移，旧消息为NULL。`user_version`更新为2。既有对话、评价、课时快照不改写。

以下新增指标按每道例题统计；讲解阶段继续记录原有讲解状态、追问与补充次数，不新增首次达标时间。原始对话的“是否例题首次达标后提交”在讲解消息中留空。

保留例题“提交次数”的原含义：每次新提交均计入，重试同一消息不重复计数。新增指标从新版首次提交开始记录：

| 字段 | 含义 |
| --- | --- |
| 有效作答次数（首次达标前） | 首次达标前提交且被归为作答的消息；排除识别出的表态和澄清。并不表示答案正确或系统评价成功。图片提交视为作答。 |
| 澄清问题次数、表态及收尾次数 | 对应类型的消息数，包含达标前后。 |
| 首次达标后提交次数 | 首次达标后全部提交，与上述类型次数可能重叠。后续状态改变也不重置首次达标时间。 |
| 首次达标时间/消息编号 | 有效评价完成并首次更新任务为达标的时间及学生消息；阶段已切换、评价失败或待复核不写入。 |
| 新统计开始时间、未分类历史提交次数 | 明确统计窗口和未回填的旧提交。旧课堂已经达标但没有时间记录时，不伪造首次达标时点。 |

原始对话追加提交类型和是否例题达标后提交；任务表现追加以上指标；评价依据追加本次例题通过结果、评价完成时间及是否跳过学习评价。系统收尾记录的JSON省略理由充分/修正字段，Excel对应列留空，避免被理解为重新判错。教师界面可查看新统计，全部消息数标为“提交次数”。

缺失历史新指标显示空白或“未记录”，不当作零。原先粗粒度的“提交次数”与新增“有效作答次数”不得直接拼接为同一个研究指标。过程评价不能替代独立前后测。

## 验证

沿用现有评价器、课堂HTTP API和导出接口进行回归，不连接正式课堂数据库。

- 评价器：纯表态不可通过、历史理由保留、选段与端点分别累计、教师自定义标准优先、证据来源及失败重试。
- 课堂API和导出：通过后收尾、达标时间、有效作答与全部提交分开、澄清不消耗次数、达标后反对意见仍评价、失败与待复核保留此前状态。
- `npm run test:ai`现包含12个匿名化真实DeepSeek场景，覆盖函数概念、函数表示方法和二分法。2026-11-16运行12/12通过，每个场景一次请求；结果保存于忽略跟踪的`artifacts/ai-review-v2.1.json`。这是有限样本回归，不是总体准确率或教学效果证明。
- 全量28项自动测试、前后端类型检查和生产构建通过；审查最后补充的“旧任务重试未通过后再通过”路径另做定向回归。临时旧版数据库迁移检查通过，旧消息不变，重复启动安全。13课时52项标准共100个细项，均覆盖且编号无重复。
- 构建保留原有的JavaScript单包超过500KB提示（约681KB，gzip约209KB）。本轮未做浏览器视觉或平板触控验收。

本次未重新评价正式课堂历史；未部署到阿里云。生产服务需更新并重启以载入新规则和执行迁移。
